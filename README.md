# molstartpy
## Pyodide+React+Molstar

https://pslacerda1.github.io/MolStarTpy/

Mol* Python integrated terminal with some functions:

* `loadPdb(pdbId)`: load PDB models.
* `tmAlignMatrix(pdbList)`: runs TM-Align in a matrix of models.
* `script01(pdbIdList)`: downloads and runs TM-Align.

It mixes React with Python and Molstar. Look for the MolstarScripts.

It is also my first project in Pyodide, React and Molstar.
