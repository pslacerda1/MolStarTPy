# molstartpy

Mol* Python integrated terminal with some functions:

* `loadPdb(pdbId)`: load PDB models.
* `tmAlignMatrix(pdbList)`: runs TM-Align in a matrix of models.
* `script01(pdbIdList)`: downloads and runs TM-Align.


Take your time, it mixes React with Python. Look for the MolstarCollection.
